# IT Support Ticketing System
Flask + MySQL + Bootstrap 5 + JavaScript + Chart.js + JWT.

Run from `backend` after copying `.env.example` to `.env` and setting MySQL credentials:
`python -m venv venv`
`venv\\Scripts\\activate` (Windows) or `source venv/bin/activate` (Linux)
`pip install -r requirements.txt`
`python seed.py`
`python app.py`
