# IT Support Ticketing System

This implementation follows the supplied SRS and UI/UX documents for the MVP: authentication, role-based access, customers, technicians, categories, tickets, assignment, status workflow, comments/internal notes, attachments, history, notifications, dashboard, reports, search/filtering, responsive Bootstrap UI and Chart.js.

The master build prompt additionally requests JWT and REST endpoints; those are implemented alongside the monolithic Flask pages. The SRS itself says REST API is not required for the initial version and lists it as a future enhancement, so the API here is an extension requested by the master prompt.
